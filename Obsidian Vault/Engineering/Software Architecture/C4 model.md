**Homepage**: [C4 model](https://c4model.com/) 

The C4 model is an easy to learn, developer friendly approach to software architecture diagramming:

1. A set of [hierarchical abstractions](https://c4model.com/abstractions) - [software systems](https://c4model.com/abstractions/software-system), [containers](https://c4model.com/abstractions/container), [components](https://c4model.com/abstractions/component), and [code](https://c4model.com/abstractions/code).
2. A set of [hierarchical diagrams](https://c4model.com/diagrams) - [system context](https://c4model.com/diagrams/system-context), [containers](https://c4model.com/diagrams/container), [components](https://c4model.com/diagrams/component), and [code](https://c4model.com/diagrams/code).
3. An additional set of supporting diagrams - [system landscape](https://c4model.com/diagrams/system-landscape), [dynamic](https://c4model.com/diagrams/dynamic), and [deployment](https://c4model.com/diagrams/deployment).
4. [Notation independent](https://c4model.com/diagrams/notation).
5. [Tooling independent](https://c4model.com/tooling).
