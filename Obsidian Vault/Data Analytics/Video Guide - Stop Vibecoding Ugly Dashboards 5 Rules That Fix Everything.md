Video: https://www.youtube.com/watch?v=z4MEVhc9_Bc - Stop Vibecoding Ugly Dashboards : 5 Rules That Fix Everything - MotherDuck Youtube

In this video, [‪@mehdio‬](https://www.youtube.com/@mehdio) breaks down 5 essential data visualization principles that separate useful dashboards from pretty ones nobody uses. Using a WHO air quality dataset and tools like Claude and MotherDuck, he walks through how to ask the right questions before building charts, pick the correct chart type using decision frameworks, apply clean design principles (colors, clutter, hierarchy, context), structure a narrative arc, and add interactivity only when it earns its place. He also shares a reusable dataviz AI skill so every vibe-coded dashboard starts from best practices instead of guesswork.
